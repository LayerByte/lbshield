# Security Policy

LBShield is a defensive monitoring project. It must never include attack generation, malware, credential theft, unauthorized exploitation, bypass tooling, or destructive payloads.

## Reporting Security Issues

Please report security issues privately to the maintainers. Do not publish exploit details before maintainers have had a reasonable opportunity to respond.

## Secrets

Never include real Discord webhook URLs, Telegram bot tokens, authentication tokens, passwords, cookies, request bodies or private keys in reports, logs, screenshots or test data.

## Scope

LBShield monitors the local server where it is installed. It does not attack external systems.
